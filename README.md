# GitHub Repository Practical

## Aim
To create a GitHub repository and push a README file using Git.

## Description
This practical demonstrates creating a repository on GitHub and managing project documentation using Git commands.

## Steps Performed
1. Created a repository on GitHub.
2. Cloned the repository to the local system.
3. Edited the README.md file using Visual Studio Code.
4. Saved the changes.
5. Staged, committed and pushed the changes to GitHub.

## Git Commands Used
- `git clone` – Clones a remote repository.
- `git add` – Stages changes.
- `git commit` – Saves changes to the local repository.
- `git push` – Uploads local commits to GitHub.

## Conclusion
Successfully created a GitHub repository and updated the README documentation using Git.
